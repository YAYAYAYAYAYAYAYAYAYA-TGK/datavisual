# Карта находок

[English](README.md) | **Русский**

Офлайн-редактор графов в одном файле для пентестеров и исследователей. Превращает разрозненные находки в наглядную карту: создавай узлы, соединяй их светящимися связями-молниями и прикрепляй заметки, команды и вывод к каждому узлу и каждой связи.

Без установки, без сервера, без зависимостей. Данные не покидают твой браузер.

## Возможности

- **Узлы 6 форм** (круг, квадрат, скруглённый, ромб, шестиугольник, треугольник), 3 размера, 6 цветов и 7 типов (домен, IP, порт, уязвимость, аккаунт, заметка или без типа)
- **Важность от 1 до 100**: чем выше значение, тем ярче светится узел
- **Статус «Проверено»** с живым счётчиком (`проверено 3/10`), чтобы не забыть непроверенное
- **Неоновые связи-молнии**: несколько анимированных плавных изогнутых разрядов на каждую связь (от 1 до 8, настраивается)
- **Названия связей в виде пузырей** и скрытое **описание у каждой связи** для команд и кода
- **Групповое выделение** области, перемещение группы и массовое изменение настроек
- **Проекты в виде вкладок браузера**, у каждого своя карта
- **Поиск**, **отмена и повтор**, привязка к сетке, «вписать», масштаб и перемещение
- **Экспорт** в JSON (резервная копия) и Markdown (черновик отчёта), импорт JSON как нового проекта
- Интерфейс на **русском и английском**
- Тёмная тема, работает на компьютере и телефоне

## Быстрый старт

1. Скачай файл `pentest-graph.html`.
2. Открой его в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Дважды кликни по полю, чтобы создать первый узел.

**GitHub Pages (по желанию):** переименуй файл в `index.html` и включи Pages в *Settings → Pages*, чтобы получить свою онлайн-копию.

## Инструкция по использованию

### Узлы

| Действие | Как сделать |
|---|---|
| Создать узел | Двойной клик по пустому полю или кнопка **+ Узел** |
| Выбрать узел | Клик по нему, справа откроется панель |
| Переместить узел | Перетащить |
| Создать связанный узел | Выбери узел и нажми **+ Связанный** в панели |
| Дублировать / удалить | Кнопки в панели или `Ctrl+D` / `Delete` |

В боковой панели задаются название, тип, форма, размер, цвет, важность, флажок **Проверено** и заметки. Поле заметок моноширинное, `Tab` вставляет отступ, поэтому там удобно хранить команды и код. Белая точка на узле означает, что у него есть заметки.

### Связи

- **Shift + перетаскивание** от одного узла к другому, либо
- кнопка **Связать** на панели, затем клик по двум узлам по очереди (работает на сенсорных экранах).

Клик по связи (или по её пузырю) открывает панель связи:

- **Название** показывается скруглённым пузырём посередине связи. Связь без названия остаётся обычной линией.
- **Описание**: большое моноширинное поле для команды, запроса или кода. Оно видно только в панели и никогда не показывается на поле. Серый значок `</>` рядом с названием говорит о том, что описание есть.
- **Копировать**, **Развернуть** направление, **Удалить**.

Типичная схема: команда записана на связи, результат лежит в целевом узле:

`[ IP ] ──(curl -i https://1.2.3.4/admin)──→ [ Ответ сервера ]`

### Групповое выделение

- Нажми **▭ Область** (переключатель) или зажми **Shift** и протяни по пустому полю, чтобы выделить область.
- `Ctrl/Cmd + клик` добавляет или убирает узел, `Ctrl+A` выделяет всё.
- Перетащи любой выделенный узел, и вся группа поедет вместе с ним.
- В боковой панели появятся общие настройки, которые сразу применяются ко всем выбранным узлам: тип, форма, размер, цвет, важность, отметить или снять «проверено», выровнять по горизонтали или вертикали, связать цепочкой, дублировать, удалить.

### Проекты (вкладки)

- **＋** создаёт проект, **двойной клик** по вкладке переименовывает, **×** закрывает (нажми дважды для подтверждения, проект при этом удаляется).
- У каждого проекта свои узлы, связи, положение камеры и настройки.

### Поиск, вид и история

- **Поиск** затемняет все узлы, у которых название, заметки или тип не совпадают с запросом.
- **Вписать** показывает всю карту целиком. Колесо мыши меняет масштаб, перетаскивание пустого поля двигает карту.
- **↶ / ↷** или `Ctrl+Z` / `Ctrl+Y` отменяют и повторяют действия.

### Настройки (⚙)

Включение молний, размах, скорость, количество разрядов, привязка к сетке, показ названий связей, очистка текущего проекта. Кнопка 🌐 переключает язык.

### Экспорт и импорт

- **JSON**: полная резервная копия текущего проекта.
- **Markdown**: чек-лист узлов с заметками в блоках кода и список связей.
- **Импорт**: загружает JSON-файл как **новую вкладку** (текущий проект не перезаписывается).

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| Двойной клик по полю | Новый узел |
| Shift + перетаскивание узел → узел | Создать связь |
| Shift + перетаскивание по полю | Выделение области |
| Ctrl/Cmd + клик | Добавить/убрать из выделения |
| Ctrl+A | Выбрать всё |
| Ctrl+D | Дублировать выделенное |
| Ctrl+Z / Ctrl+Y | Отмена / повтор |
| Delete / Backspace | Удалить выделенное |
| Esc | Снять выделение |

## Приватность и хранение данных

- Всё работает локально в одном HTML-файле. Никаких сетевых запросов, аналитики и аккаунтов.
- Данные хранятся в `localStorage` браузера. **Очистка данных браузера удалит твои карты.** Регулярно делай экспорт в JSON.
- Локально открытый файл и онлайн-копия (например, на GitHub Pages) используют разные хранилища. Переносить карты между ними можно через экспорт и импорт JSON.
- Бережно относись к экспортированным файлам: в них могут быть данные клиентов.

## Ограничения

- Нет совместной работы в реальном времени и облачной синхронизации (для обмена картами используй JSON-файлы и Git).
- Объём хранилища ограничен браузером (обычно несколько МБ), для текстовых карт этого более чем достаточно.
- На сенсорных экранах нет клавиши Shift, используй кнопки **Связать** и **▭ Область**.
